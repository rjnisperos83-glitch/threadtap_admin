# ThreadTap Admin (Flutter, seller/merchant app)

See the setup guide in the chat reply for the full Firebase walkthrough,
including how to promote a user to "admin".

Quick start once Firebase is configured:
1. flutter pub get
2. dart pub global activate flutterfire_cli   (if not already)
3. flutterfire configure   (SAME Firebase project as the shopper app)
4. flutter run
